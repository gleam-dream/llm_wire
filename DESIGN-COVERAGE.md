# LLM Wire design coverage: current release candidate

This ledger distinguishes tested delivery from remaining design scope. A green local suite is evidence only for the named exercised paths. It does not establish full provider conformance or release readiness.

| OpenAI Responses and Anthropic Messages typed text/tool calls                                                         | Implemented for the admitted text/tool/multimodal subset                       | Preparation, buffered collection, owned streaming, tool admission, typed terminal outcomes, exact request-local result coverage, and typed text/image content are in src/llm_wire/internal/api.gleam, src/llm_wire/internal/openai.gleam, and src/llm_wire/internal/anthropic.gleam. | Blueprint tool schema admission and terminal-only executable tool batches                                             | Implemented and tested                                                         | Tool names follow the portable grammar and schema contracts are admitted before transport. Reducers only decode calls; the runtime admits each completed batch once, for built-in and custom providers alike. Duplicate call IDs and argument byte bounds always fail. Calls are released together only after a provider terminal confirms the batch. | SSE framing and provider fragmentation                                                                                | Implemented and tested for selected frames                                     | LF/CRLF, split CRLF/UTF-8, multiline fields, bounded event counts, representative frames at every byte boundary, and complete OpenAI/Anthropic/Google text interactions at every two-chunk byte split are covered by test/llm_wire_sse_test.gleam and test/llm_wire_provider_fragmentation_test.gleam. This is not a fuzz corpus or all-event permutation.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| OTP stream owner, deadlines, bounded progress, and cleanup                                                            | Implemented and tested for exercised paths                                     | The owner serializes reads, has one outstanding transport credit, bounds queued progress and body bytes, arbitrates read-timeout races, and cleans up on tested close, consumer death, terminal, disconnect, and shutdown paths. Evidence is in test/llm_wire_owner_test.gleam, test/llm_wire_wave1_regression_test.gleam, and the pool tests. The complete close/death/deadline/kill-at-every-state matrix remains release hardening for the LLM Wire owner.                                                                                                                                                                                                                                                                                                                                                                                                                            |
| Optional Gun connection lease/reuse pool                                                                              | Implemented and tested as an explicit runtime path                             | llm_wire/pool starts a bounded GenServer; runtime.stream_with_pool and run_with_pool route PreparedCall-only requests through it. Leases are keyed by host/port/TLS identity, reused after healthy check-in, bounded per target/total and by waiter count, deadline-aware, and monitored for bridge/client/Gun process loss. Closing one stream does not cancel another. Pool lifecycle, reuse, owner death, FIFO, queue cap, timeout, and shutdown evidence is in test/llm_wire_pool_test.gleam. The no-pool API intentionally keeps one connection per request.                                                                                                                                                                                                                                                                                                                        |
| Strict 16 KiB response-header allocation bound                                                                        | Decision required                                                              | The local complete-header-in-one-write test proves that a 17 KB header is rejected. It does not prove a 16 KiB pre-allocation bound. Pinned Gun 2.6.0 checks its buffered header limit only if the terminator is absent; a complete block goes to handle_head/6 and Cowlib cow_http:parse_headers/1 before adapter-level size measurement. No second parser was added. The concrete decision is whether to take an upstream Gun/Cowlib change that checks the full block before assembly, or select a transport with that documented guarantee. Owner: LLM Wire maintainers; resolve before release acceptance.                                                                                                                                                                                                                                                                          |
| TLS, redirects, response/body bounds, compression policy, and absolute setup deadline                                 | Implemented for exercised HTTP paths                                           | Local TCP/TLS tests cover pinned CA, hostname/untrusted CA rejection, redirects, compressed stream rejection, body cap, chunked transfer, setup deadline and disconnects. Gun remains a thin adapter; no additional HTTP parser/client package was introduced.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |

Audio, video, provider output media, and broader content parity remain open. Owner: LLM Wire, future scope.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |

## Conversation ownership and test replay (2026-09-29)

| Contract                              | Status                        | Evidence                                                                                                                                                                      |
| ------------------------------------- | ----------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Caller-owned histories                | Implemented                   | `types.AssistantTurn`, `AssistantTurnMessage`, explicit request construction, request-local result validation; session, integration and turn tests.                           |
| Workflow continuation and persistence | Assigned to Fabric            | No continuation, checkpoint, source digest or replay codec API. [Fabric migration](docs/fabric-migration.md) records the consumer work; Fabric sources have not been changed. |
| Offline cassette playback             | Implemented                   | [Boundary contract](docs/caller-owned-conversation.md), `llm_wire/cassette`, `testing.start_matched`, fixed version-1 disk fixtures and cassette tests.                       |
| Live cassette recording               | Deferred                      | Playback accepts authored/imported fixtures. No automatic recorder or fixture sanitization policy is implemented.                                                             |
| Retry prospect                        | Implemented; host owns policy | `retry.assess` and retry tests, with unknown fallback and no automatic retry.                                                                                                 |

The accepted local contract is [caller-owned-conversation.md](docs/caller-owned-conversation.md).
The parent oversight design needs the same ownership revision during the later
Fabric integration; this contract supersedes its continuation rules for this package.
