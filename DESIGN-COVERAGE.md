# LLM Wire design coverage: current release candidate

This ledger distinguishes tested delivery from remaining design scope. A green local suite is evidence only for the named exercised paths. It does not establish full provider conformance or release readiness.

| Capability                                                                                                            | State                                                                          | Evidence, limit, owner, and wave                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| --------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| OpenAI Responses and Anthropic Messages typed text/tool calls                                                         | Implemented for the admitted text/tool/multimodal subset                       | Preparation, buffered collection, owned streaming, tool admission, typed terminal outcomes, exact tool continuation, and typed text/image content are in src/llm_wire/internal/api.gleam, src/llm_wire/internal/openai.gleam, and src/llm_wire/internal/anthropic.gleam. Provider reducer and local HTTP evidence is in the provider suites and test/llm_wire_integration_test.gleam. Audio/video and the wider provider option matrix remain open under the LLM Wire owner.                                                                                                                                             |
| Google GenerateContent text/tool profile                                                                              | Implemented for the admitted subset                                            | Request and continuation encoding, SSE reduction, text, inline image parts, tool calls, usage, structured-schema subset, refusal, output limit, malformed payload, and loopback tests are in src/llm_wire/internal/google.gleam, src/llm_wire/internal/api.gleam, and test/llm_wire_google_test.gleam. Missing FunctionCall IDs receive a deterministic per-turn application identity that is omitted from provider continuation fields. thoughtSignature is retained as opaque provider state and emitted on continuation. Durable provider state remains outside the current API. No broad-model parity claim is made. |

| Strict structured output                                                                                              | Implemented for the admitted strict schema subset                              | Provider schema projection and runtime Blueprint validation/native decoding are exercised in test/llm_wire_api_test.gleam and test/llm_wire_google_test.gleam. Google unsupported schema forms fail local admission. Generated codecs and wider provider schema profiles remain outside the tested subset.                                                                                                                                                                                                                                                                                                               |
| PreparedCall-only transport boundary and opaque originating continuation                                              | Implemented and tested                                                         | Only an opaque api.PreparedCall crosses the internal client and Gun transport. Continuation retains its prepared origin, provider/model, and admitted calls; exact result coverage is checked before preparation. The external-package probe is test/external_package_boundary.sh; local HTTP origin substitution and provider-specific wire restoration are in test/llm_wire_integration_test.gleam.                                                                                                                                                                                                                    |
| Ordinary JSON provider boundary                                                                                       | Implemented and tested                                                         | OpenAI, Anthropic, Google, and continuation argument boundaries use the standard Gleam JSON parser and decoders. Blueprint remains reserved for schema-bearing contracts and validation. Duplicate-member rejection is not a package contract. Evidence: each provider reducer suite and continuation tests.                                                                                                                                                                                                                                                                                                             |
| Usage and selected terminal/refusal states                                                                            | Implemented for named cases; cross-provider option coverage remains incomplete | OpenAI, Anthropic, and Google have typed text/tool/refusal/output-limit/failure outcomes and usage reducers. Provider suites cover cumulative Anthropic usage replacement, Google usage, OpenAI refusal and reasoning summary, and selected stops. Provider-specific reasoning parity, exhaustive stop-reason mapping, and the full usage/option matrix remain outside the tested subset.                                                                                                                                                                                                                                |
| Provider-neutral request option admission                                                                             | Partial; Wave 4 slice                                                          | Common token, temperature, top-p, and stop-sequence fields are encoded per provider where supported; OpenAI Responses stop sequences are rejected before transport. Provider-scoped OpenAI prompt-cache keys and Google cached-content references are admitted and cross-provider use fails before transport. Reasoning, usage detail, and the remaining option matrix are open.                                                                                                                                                                                                                                         |
| Automatic retry policy                                                                                                | Deferred; Wave 3 remainder                                                     | The adapter exposes transport/progress retry evidence and bounded Retry-After hints but performs no automatic retries. This is fail-closed replay behavior, not ReqLLM retry parity. Policy for failures before progress, effect ambiguity, hints, deadline budget, and retry ownership remains a future policy decision.                                                                                                                                                                                                                                                                                                |
| SSE framing and provider fragmentation                                                                                | Implemented and tested for selected frames                                     | LF/CRLF, split CRLF/UTF-8, multiline fields, bounded event counts, representative frames at every byte boundary, and complete OpenAI/Anthropic/Google text interactions at every two-chunk byte split are covered by test/llm_wire_sse_test.gleam and test/llm_wire_provider_fragmentation_test.gleam. This is not a fuzz corpus or all-event permutation.                                                                                                                                                                                                                                                               |
| OTP stream owner, deadlines, bounded progress, and cleanup                                                            | Implemented and tested for exercised paths                                     | The owner serializes reads, has one outstanding transport credit, bounds queued progress and body bytes, arbitrates read-timeout races, and cleans up on tested close, consumer death, terminal, disconnect, and shutdown paths. Evidence is in test/llm_wire_owner_test.gleam, test/llm_wire_wave1_regression_test.gleam, and the pool tests. The complete close/death/deadline/kill-at-every-state matrix remains release hardening for the LLM Wire owner.                                                                                                                                                            |
| Optional Gun connection lease/reuse pool                                                                              | Implemented and tested as an explicit runtime path                             | llm_wire/pool starts a bounded GenServer; runtime.stream_with_pool and run_with_pool route PreparedCall-only requests through it. Leases are keyed by host/port/TLS identity, reused after healthy check-in, bounded per target/total and by waiter count, deadline-aware, and monitored for bridge/client/Gun process loss. Closing one stream does not cancel another. Pool lifecycle, reuse, owner death, FIFO, queue cap, timeout, and shutdown evidence is in test/llm_wire_pool_test.gleam. The no-pool API intentionally keeps one connection per request.                                                        |
| Strict 16 KiB response-header allocation bound                                                                        | Decision required                                                              | The local complete-header-in-one-write test proves that a 17 KB header is rejected. It does not prove a 16 KiB pre-allocation bound. Pinned Gun 2.6.0 checks its buffered header limit only if the terminator is absent; a complete block goes to handle_head/6 and Cowlib cow_http:parse_headers/1 before adapter-level size measurement. No second parser was added. The concrete decision is whether to take an upstream Gun/Cowlib change that checks the full block before assembly, or select a transport with that documented guarantee. Owner: LLM Wire maintainers; resolve before release acceptance.          |
| TLS, redirects, response/body bounds, compression policy, and absolute setup deadline                                 | Implemented for exercised HTTP paths                                           | Local TCP/TLS tests cover pinned CA, hostname/untrusted CA rejection, redirects, compressed stream rejection, body cap, chunked transfer, setup deadline and disconnects. Gun remains a thin adapter; no additional HTTP parser/client package was introduced.                                                                                                                                                                                                                                                                                                                                                           |
| Sinal lifecycle observations                                                                                          | Implemented for current fixed metadata schema                                  | A named test checks stage/provider/fixed outcome and confirms request content is absent. Broader observation points remain outside the current fixed metadata schema.                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| Multimodal message content                                                                                            | Partial; Wave 4 slice                                                          | Public typed text, remote image URL, and inline base64 image parts encode for OpenAI Responses. Text and inline image parts encode for Anthropic Messages and Google GenerateContent; unsupported provider combinations fail before transport. Audio, video, provider output media, and broader content parity remain open. Evidence: test/llm_wire_api_test.gleam and test/llm_wire_wave4_oracle_test.gleam.                                                                                                                                                                                                            |
| Embeddings                                                                                                            | Deferred; Wave 4 complexity candidate                                          | No embeddings request/result API or provider matrix exists. Provider endpoints and result shapes differ from the streaming PreparedCall contract; a small unary typed endpoint could be added without changing the streaming core, but it needs separate response/error/usage limits and oracle fixtures. Owner: LLM Wire, future scope.                                                                                                                                                                                                                                                                                 |
| Prompt caching                                                                                                        | Partial; Wave 4 slice                                                          | OpenAI `prompt_cache_key` and Google `cachedContent` references are typed, encoded, and provider-scoped before transport. Anthropic cache breakpoints attach to content blocks and are not silently represented by the common reference variants. Cache usage detail and process-local response caching remain open. Evidence: test/llm_wire_api_test.gleam and test/llm_wire_wave4_oracle_test.gleam.                                                                                                                                                                                                                   |
| Broad provider reasoning parity                                                                                       | Partial; Wave 4 slice                                                          | OpenAI reasoning-summary text remains supported and Google thoughtSignature is retained as opaque provider state through tool continuation. Anthropic thinking blocks, detailed usage fields, and durable/versioned state remain open.                                                                                                                                                                                                                                                                                                                                                                                   |
| WebSocket/realtime, batches/background jobs, remote cancellation acknowledgement, persistable continuation            | Deferred; Wave 4 complexity candidates                                         | No such transport or state-restoration surface is implemented. Existing Gun SSE ownership is insufficient for bidirectional realtime or remote cancellation acknowledgement; a separate transport/state machine is required. Batch/background endpoints also need polling and durable identity. Owner: LLM Wire, future scope.                                                                                                                                                                                                                                                                                           |
| Adapter evaluation, exhaustive upstream differential fixtures, fuzz/soak/leak tests, OTP 27–28, and release/API audit | Partial; Wave 4 selected oracle ports                                          | ReqLLM v1.24.0 selected behavior is now ported into executable local cases in test/llm_wire_wave4_oracle_test.gleam and runs in the package suite; the full ReqLLM suite and live providers remain unrun. Fuzz/soak/leak tests, multi-OTP and final release/API audit remain open.                                                                                                                                                                                                                                                                                                                                       |
