## HTTP Gun adoption (2026-09-30)

The accepted [HTTP ownership contract](docs/http-gun-migration.md) and
[validation report](docs/http-gun-validation.md) supersede older local transport
receipts. The same semantic owner/reducers remain responsible for all rows above.
One production adapter uses only documented HTTP Gun consumer modules. External
consumers, H1, verified TLS, negotiated H2, owner/worker cleanup, fixed deadlines,
byte-fragmented built-in providers and simultaneous 1/10/100/1000 callers are
measured on OTP 28. Other OTP/OS matrices and universal memory or performance
claims are unmeasured. Production handwritten FFI is zero.
