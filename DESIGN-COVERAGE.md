# Design Coverage Ledger: `oversight/llm-design.md`

This document maps each requirement section from `/code/gleam-dream/oversight/llm-design.md` to its implementation and test status in `llm_wire`.

Status definitions:

- **`implemented`**: Built and active in the codebase.
- **`tested`**: Covered by deterministic unit or local integration test suites.
- **`scaffolded`**: Types, signatures, or ports defined in the facade; internal mechanics stubbed or deferred.
- **`backlog`**: Formally retained in the design contract; planned for subsequent development waves.

## Retained Backlog Inventory

The following items are deferred to future waves and remain active in the product design:

1. **Google Gemini Provider**: Streaming and buffered protocol adapter matching Google's Content API.
2. **Multimodal Content**: Support for image, audio, and binary inputs in request structures.
3. **Prompt Caching & Reasoning Streams**: Decoding provider-specific reasoning deltas and caching tokens.
4. **Compile-Time Codec Generation**: Automated code generator with SHA-256 freshness proofs for schema-bearing contracts.
5. **WebSocket / Realtime API Transports**: Bidirectional persistent socket protocols.
6. **ReqLLM FFI Spike**: Differential benchmarking against Mix/Elixir ReqLLM FFI backend.
